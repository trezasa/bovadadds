Kids Learning World — Educational Game Website
==============================================

Start: index.html

Pages
-----
- index.html         (Main homepage for Kids Learning World)
- game.html          (Hub page listing all available games)
- math-whiz.html     (Playable Math Whiz canvas game)
- word-scramble.html (Playable Word Scramble game)
- leaderboard.html   (Shows local top scores for Math Whiz)
- about.html
- blog.html
- faq.html
- services.html
- privacy.html
- terms.html
- contact.html
- lander.html        (Placeholder for 18+ users, e.g., parents/partners)
- lande.html         (Placeholder for under-18 users)
- robots.txt
- sitemap.xml

Notes
-----
- The website is branded as "Kids Learning World", an educational platform for children.
- The font has been updated to 'Comic Neue' for a kid-friendly feel.
- An age-gate popup shows on first visit. Buttons can route to different pages for parents vs. children. You can change these destinations inside assets/js/main.js.
- The site is fully responsive and works on desktop, tablet, and mobile.
- The `game.html` page acts as a hub. New games can be added by creating a new HTML file for the game and linking to it from `game.html`.
- High scores for the "Math Whiz" game are stored in the browser's localStorage.

Enjoy!
